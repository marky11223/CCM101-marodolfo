# Laboratory 01 – Welcome to the Cloud

## Mission Overview
This laboratory introduced me to working in a cloud-based Linux environment using KillerCoda.  
The goal was to set up a portfolio repository on GitHub and document my progress with proper evidence.

## Objectives
- Explore a cloud Linux playground (Ubuntu 24.04)
- Create and manage user accounts with sudo privileges
- Collect system information (OS, kernel, CPU, memory, disk)
- Organize files into a clear folder structure
- Document outputs using Markdown
- Push all work to GitHub as a professional portfolio

## Activities Performed
1. Launched Ubuntu playground on KillerCoda.  
2. Ran commands to gather system information:
   - `cat /etc/os-release`
   - `uname -r`
   - `lscpu`
   - `free -h`
   - `df -h`
3. Created Markdown files:
   - `system-information.md`
   - `about-me.md`
   - `reflection.md`
4. Organized files into the required structure.  
5. Added screenshots for each checkpoint.  
6. Pushed everything to GitHub.
