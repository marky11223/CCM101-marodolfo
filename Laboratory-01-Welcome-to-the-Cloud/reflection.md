# Final Reflection – Laboratory 01: Welcome to the Cloud

## What I Learned
Through this laboratory, I gained practical experience in using Linux commands within a cloud‑based environment. I learned how to create and manage users,
configure permissions, and navigate the filesystem. I also practiced version control with Git and GitHub, which helped me understand the importance of 
tracking changes and maintaining organized repositories. These skills are foundational for cloud computing and professional software development.

## Challenges Faced
One of the main challenges I encountered was handling file uploads and ensuring that screenshots were properly placed in the repository.
Case sensitivity in Linux filenames also caused errors when moving or renaming files. Additionally, configuring Git identity and pushing commits required careful 
attention to detail. These difficulties taught me patience and the value of precise commands.

## Insights
This activity highlighted the importance of documentation and evidence in technical work. Screenshots and reflections serve not only as proof of completion 
but also as a way to communicate progress clearly. I realized that cloud engineers must balance technical execution with proper record‑keeping.
Publishing the repository through GitHub Pages transformed my work into a professional portfolio, showing that cloud computing is not just about commands but 
also about presentation and communication.

## Conclusion
Overall, this laboratory strengthened my confidence in using Linux, Git, and GitHub. It showed me how cloud computing environments can be leveraged for
learning and collaboration. The experience will be valuable as I continue my journey toward becoming a graphic designer with strong technical foundations.
