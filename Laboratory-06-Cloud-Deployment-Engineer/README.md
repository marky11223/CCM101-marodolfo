# Laboratory 06 – Cloud Deployment Engineer

## Mission Overview

This laboratory focuses on deploying a multi-tier private cloud storage application using Docker Compose. The application consists of a Nextcloud web application and a MariaDB database running as separate containers.

## Objectives

- Explain multi-tier application architecture.
- Understand the structure of a docker-compose.yml file.
- Create a Docker Compose configuration using YAML.
- Deploy a Nextcloud and MariaDB multi-container application.
- Access a containerized application through a browser.
- Document Infrastructure as Code concepts.

## Commands Executed

```bash
mkdir nextcloud-deployment
cd nextcloud-deployment
docker-compose up -d
docker-compose ps
docker-compose down
```

## Skills Learned

- Multi-tier architecture
- Docker Compose
- YAML configuration
- Linux command-line text editing
- Container deployment
- Container networking
- Infrastructure as Code
- Technical documentation
