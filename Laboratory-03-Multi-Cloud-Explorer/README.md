# Laboratory 03 - Multi-Cloud Explorer

## Mission Overview

This laboratory explores Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). The activity compares their services, advantages, infrastructure, and suitability for different business requirements.

## Linux Server Investigation

### Operating System

The Linux server is running **Ubuntu 24.04.4 LTS (Noble Numbat)** with an **x86_64** architecture.

### CPU Information

The server has **1 CPU** using an **Intel Xeon E312xx (Sandy Bridge, IBRS update)** processor. The virtualization environment uses **KVM**.

### Memory

The server has **1.9 GiB of total memory**, with approximately **420 MiB used**, **835 MiB free**, and **1.4 GiB available**.

### Disk Space

The main filesystem `/dev/vda1` has **19 GB of total space**, with **5.4 GB used** and **13 GB available**, resulting in **30% disk usage**.

## Cloud Migration

If this Linux server were migrated to the cloud, equivalent virtual machine services could be used from each major cloud provider.

| Cloud Provider | Service |
|---|---|
| AWS | Amazon EC2 |
| Microsoft Azure | Azure Virtual Machines |
| Google Cloud Platform | Compute Engine |
