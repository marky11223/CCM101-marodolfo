# Mission Reflection

Among the three cloud platforms, AWS impressed me the most because it offers many different services that can support various types of organizations and applications. While completing this mission, I also realized that AWS, Microsoft Azure, and Google Cloud Platform have many similarities. All three provide important cloud services such as virtual machines, storage, networking, databases, identity management, and Kubernetes, while also offering scalable infrastructure for different workloads. However, choosing a cloud platform depends greatly on the needs of the business. Factors such as budget, existing technologies, performance requirements, scalability, and the goals of the organization should be considered before making a decision. For instance, a university that already uses Windows Server, Microsoft 365, and Active Directory would likely benefit from Azure because of its compatibility with Microsoft technologies, while an AI research company could take advantage of Google Cloud's strong AI and machine learning services. Through this activity, I learned that being a Cloud Solutions Consultant is not simply about choosing the most popular cloud provider. It involves understanding the client's needs, comparing the available services, considering the strengths of each platform, and recommending the option that provides the best solution. I also learned how important it is to match technical features with actual business requirements. Completing this mission improved my GitHub Cloud Computing Portfolio by adding organized research, comparison tables, client recommendations, Linux server investigation results, and supporting screenshots. Overall, this activity gave me a better understanding of how AWS, Azure, and GCP can be evaluated and selected based on real-world business needs, while also helping me improve my technical documentation and cloud computing knowledge.
