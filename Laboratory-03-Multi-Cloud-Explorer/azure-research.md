# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a public cloud computing platform developed by Microsoft. It provides services for computing, storage, networking, databases, identity, analytics, artificial intelligence, and application development.

## Global Infrastructure

Azure operates a global infrastructure consisting of regions and availability-related infrastructure. Organizations can deploy resources in different geographic locations to support performance, availability, and regulatory requirements.

## Cloud Management Console

The Azure portal is a web-based management interface used to create, configure, monitor, and manage Azure resources.

## Four Core Services

1. Azure Virtual Machines - Virtual machines
2. Azure Blob Storage - Object storage
3. Azure Virtual Network - Private networking
4. Microsoft Entra ID - Identity and access management

## Three Advantages

1. Strong integration with Microsoft technologies
2. Wide range of enterprise cloud services
3. Scalable infrastructure and applications

## Typical Enterprise Use Cases

- Windows Server workloads
- Microsoft enterprise applications
- Cloud migration
- Web application hosting
- Database services
- Identity and access management
