# Final Reflection

Throughout Missions 1 to 10, I gained practical knowledge about cloud computing, virtualization, Linux administration, Docker containers, networking, and security.

For Mission 10, I successfully deployed a WordPress and MariaDB application using Docker Compose inside an Ubuntu Server virtual machine. I configured persistent storage, implemented firewall rules, and created a backup automation script with cron scheduling.

One challenge I encountered was configuring VirtualBox and working with Ubuntu Server. I resolved these issues through testing, troubleshooting, and learning how Linux services and Docker containers work together.

The most important lesson I learned is the importance of automation, security, and reliable backups in cloud environments. This experience improved my confidence in deploying and managing cloud-based systems.
