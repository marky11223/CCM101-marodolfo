# Automation Research

## Bash Script
A Bash script is a text file containing shell commands that can run together to automate a task. The `#!/bin/bash` line, called the shebang, tells the system to use Bash to interpret the script.

## Variables
Variables store values, such as folder paths, under a reusable name. Using `$BACKUP_DIR` makes a script easier to update because the path can be changed in one place rather than repeated throughout the code.

## Cron Job
A cron job is a scheduled task managed by the Linux cron service. It is useful in cloud operations because routine work, such as backups, can run at a specified time without someone starting it manually.
