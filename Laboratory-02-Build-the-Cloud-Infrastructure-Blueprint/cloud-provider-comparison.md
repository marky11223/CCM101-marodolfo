## Guide Questions & Analysis

### 1. Which cloud provider offers the broadest range of services? Explain your answer.
Amazon Web Services (AWS) offers the broadest range of cloud services due to its pioneer advantage and mature global infrastructure footprint. It hosts over 200 fully featured services spanning compute, storage, serverless architectures, machine learning, and Internet of Things (IoT).

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?
Microsoft Azure is recommended for organizations relying heavily on Microsoft software. It offers seamless, native integration with enterprise tools like Windows Server, Active Directory, and Office 365, while providing significant cost savings through the Azure Hybrid Benefit licensing model.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?
Google Cloud Platform (GCP) is widely recognized as an industry leader in AI, ML, and container orchestration capabilities. Having originally developed Kubernetes, Google provides industry-standard managed container services via Google Kubernetes Engine (GKE) along with advanced AI solutions like Vertex AI.

### 4. What similarities did you observe among the three cloud providers?
All three major cloud providers offer the same fundamental infrastructure building blocks: virtual compute instances, scalable object and block storage, virtual private networking, and identity access controls. Additionally, each platform utilizes pay-as-you-go utility pricing models and operates across highly available global regions and availability zones.
