# Mission 5: The Cloud Data Engineer

## Mission Overview

This laboratory focuses on cloud object storage using MinIO. MinIO was deployed using Docker to create an S3-compatible object storage environment. A bucket named `client-photos` was created and a sample file was uploaded through the MinIO Web Console.

## Objectives

- Differentiate Block, File, and Object Storage.
- Deploy MinIO using Docker.
- Access a cloud service through port forwarding.
- Create a storage bucket and upload an object.
- Document cloud storage operations using Markdown.

## Tools Used

- KillerCoda Playground
- Ubuntu
- Docker
- MinIO
- GitHub
- Web Browser

## Skills Learned

- Understanding cloud storage types.
- Deploying MinIO using Docker.
- Using Docker environment variables.
- Accessing a web service through a forwarded port.
- Creating and managing an object storage bucket.
- Uploading objects to cloud storage.
- Documenting cloud deployment procedures.
